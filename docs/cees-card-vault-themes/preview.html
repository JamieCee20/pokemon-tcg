Cee's Card Vault pack themes

Open via a local server. Note: SVGs loaded through img tags cannot load web fonts, so the lettering falls back to Impact here; in the app, inline the SVGs or convert text to paths (see HANDOVER.md).

2. Ember Forge (common)

Open 25 packs of any theme.

3. Tidal Depths (uncommon)

Pull 15 Water-type cards.

4. Verdant Grove (uncommon)

Open packs on 7 different days.

5. Storm Circuit (rare)

Pull 5 holo rares.

6. Eclipse Prism (secret)

Unlock all five other themes.
